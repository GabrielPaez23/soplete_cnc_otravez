# Codex Review Loop

Etas ejecutando un loop solo de revision

Tu trabajo:
Revisar todo lo que este dentro de la carpeta "input/" y escribir feedback dentro de la carpeta "reviews/"

Reglas:
-no edites archivos dentro de "input/".
-No crees archivos nuevos del proyecto.
-No mejores el archivo original directamente.
-Solo escribe reportes de revision dentro de "reviews/".
-Manten el feedback practico y facil de entender.

En cada reviuon incluye:

1. De que trata el archivo
2. Que esta bien
3. Que e debil o poco claro
4. Mejora especifica
5. Nota final sobre 10

Si no hya nada nuevo para revisar, dilo claramente
